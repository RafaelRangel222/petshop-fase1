# PetBest - Os melhores amigos do seu pet

Este repositório contém a versão de desenvolvimento da plataforma web para o **PetBest**, desenvolvida como projeto prático da disciplina de Sistemas Web.

---

# Visão Geral do Projeto

Nesta primeira fase, a plataforma foi estruturada utilizando exclusivamente HTML5, sem a inclusão de estilizações (CSS/Bootstrap) ou funções utilizando JavaScript, atendendo aos requisitos do enunciado da fase 1.

---

# Estrutura do Site e Conteúdo

A página é composta por uma estrutura que contém:

1. **Cabeçalho (`<header>`)**: 
   - Nome do petshop, slogan e menu de navegação.

2. **Catálogo de Produtos (`<main> > <section>`)**:
   - Organizado em **3 categorias** (2 produtos por categoria):
     - **Acessórios**: Coleira Peitoral e Brinquedo Morde-Morde.
     - **Rações Não Perecíveis**: Ração para Cães Adultos (15kg) e Ração para Gatos Castrados - Golden Salmão (1kg).
     - **Higiene e Limpeza**: Tapete Higiênico Chalesco 90x60cm para Cães (30 unidades) e Shampoo Sanol Neutro para cães e gatos (500ml).
   - Cada item apresenta foto, descrição e preço.

3. **Serviços Oferecidos**:
   - Pacotes de **Banho e Tosa** com descrição, preço e indicação clara da opção de **tele-busca** (com ou sem tele-busca).

4. **Rodapé (`<footer>`)**:
   - Informações de contato (endereço, telefone e e-mail) e direitos autorais.
